# stack2rules v1.0.0

First release of the offline, zero-runtime-dependency Python CLI that generates
framework-specific CLAUDE.md guidance from project manifests.

## Features

- Detect supported Python and Node.js technologies from package.json,
  requirements.txt and pyproject.toml.
- Generate deterministic guidance for FastAPI, Django, Pandas, React, Next.js,
  Tailwind CSS, TypeScript and other supported technologies.
- Read only allowlisted root files, skip unsafe/malformed inputs, sanitize
  diagnostics and preserve existing output files.
- Include three synthetic examples, 29 regression tests and a reusable
  PowerShell demonstration covering 13 technology sections and overwrite protection.

## Requirements and installation

Python 3.11+ and a local filesystem supporting hard links are required.
Download the attached wheel, then run from the download directory:

```sh
python -m pip install ./stack2rules-1.0.0-py3-none-any.whl
stack2rules --help
```

Run `stack2rules` in your project's root, or use:

```sh
stack2rules --dir /path/to/project
```

To repeat the PowerShell demo from a source checkout with stack2rules installed:

```powershell
& .\scripts\test-demo.ps1 -KeepProject
```

## Verification and limitations

The release workflow runs only after CI succeeds on its source commit. CI
tests Python 3.11–3.14 on Linux, macOS and Windows, including example generation
and isolated wheel installation. Platform-specific tests may skip when their
filesystem capability is unavailable. The PowerShell demo runs on Windows.

Detection reflects declared dependencies, not confirmed runtime usage or exact
framework versions. The scanner does not recurse into monorepo subprojects or
follow requirements includes. Existing output is deliberately never overwritten.

The assets include a wheel, source distribution and SHA256SUMS.txt. This is a
GitHub release; PyPI publication is separate. Distributed under the MIT license.
